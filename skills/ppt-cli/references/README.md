# PowerPoint CLI References

This folder contains behavioral guidance and quirks documentation for the PowerPoint CLI.

**Note for developers:** Run `dotnet build -c Release` to generate SKILL.md and copy shared content from `skills/shared/` to this folder.

**Note for users:** When distributed as a skill package, this folder is pre-populated with all necessary reference files.

## Contents (populated by build)

- `behavioral-rules.md` - Core execution rules
- `cli-commands.md` - Generated command and action reference
- `generation-pipeline.md` - Deck generation pipeline guidance
- `ppt_agent_mode.md` - Agent mode (watch PowerPoint work live)
- `slide-design-principles.md` - Slide design principles
- `slide-design-review.md` - Slide design review checklist
